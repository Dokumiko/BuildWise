# AI-Assisted PC Configuration System

Frozen v0.1 modular-monolith skeleton. The current scope is the catalog data foundation only: FastAPI, SQLAlchemy 2.0, Alembic, Pydantic 2, PostgreSQL 17, and a Next.js TypeScript shell.

Compatibility analysis, recommendations, LLM features, and non-PostgreSQL infrastructure are intentionally not implemented.

See `backend/README.md` and `frontend/README.md` for setup commands.
